02CASE STUDY

Enforcing a data regulation with 18 rules in Excel.

Portfolio case study - all data is fictional and simulated. PROBLEM A data-governance regulation classifies every transaction field as mandatory or optional and defines what valid means for each one. The batch is 5,000 records. Manual review is slow, two people reach two different answers, and nothing is auditable. APPROACH I treated the regulation as configuration, not code. A Rules sheet holds 18 rules - patterns, lengths, reference lookups, a cross-field product/category map, numeric ranges, date windows and composite duplicate detection - each with a severity and an auto-fix switch. The VBA engine cleans first and judges second. Deterministic fixes - casing, spaces, phone formats, canonical reference values, dates - are applied and logged cell by cell. Then the rules run, every rejected cell is coloured, and each row is stamped: valid, warning, or invalid. RESULT 3,851 records accepted. 413 accepted with warnings. 736 rejected with a documented reason. 1,263 violations caught before reporting - the biggest sources being a high-value approval threshold, invalid e-mail and phone formats, and cities outside the registered service area. 5,256 cells repaired automatically. Compliance stopped being an opinion. It became a 77.02% figure with an error report, split exports and an audit log behind it - and a dashboard the management team can read in ten seconds.

03CASE STUDY

One sales model, nine measures, one source of truth.

Portfolio case study - all data is fictional and simulated. PROBLEM Sales reporting usually lives in scattered spreadsheets. Each region sends its own file, totals are rebuilt by hand, and management asks the same questions every month: how are we doing, which region is slipping, and which product line makes the margin. APPROACH I modelled the data as a proper semantic model in Power BI instead of one large sheet. A Sales fact table (5,000 transactions, January 2023 to December 2024) is linked to a generated Calendar table, so every time-based question uses the same date logic. Business definitions live in nine DAX measures: sales, cost of goods, profit, margin, transaction count, average per transaction, same period last year, and year-over-year growth. The visuals do not recalculate anything themselves. THE DASHBOARD One page, readable in ten seconds: four KPI cards (sales, profit, margin, transactions), a year slicer, a monthly sales trend, and two column charts - sales by region and profit by product category. THE PROJECT FILES The data source path is set once in a parameter, so the same model can point at a real export. The project is saved as PBIP, a text-based format that works with Git, and includes a Node script that regenerates the sample data. WHAT IT SHOWS The point is not the charts. Every number on the page comes from one definition, and changing a definition means changing one measure.

04CASE STUDY

Affiliate picks people can trust: the GoOdays case study.

Live case study - a real site with real products. PROBLEM Indonesian shoppers are flooded with best-product lists that are sponsored in disguise. Affiliate sites that show fake ratings and fake discounts lose trust, and trust is what makes a click turn into a purchase. APPROACH I built GoOdays around one rule: say less, but only what can be verified. A top pick carries a rating only when it comes from real research. A deal card shows a price only after someone has checked it on Shopee, and it disappears on its own after its valid-until date. Every buy button is a Shopee Affiliate link with a SubID per placement, so the report shows where the clicks come from, not just how many there are. THE BUILD Vanilla HTML, CSS and JavaScript, with Supabase for editable content and an admin panel, deployed on Cloudflare Pages with no build step. Full Indonesian and English copy, a 10-point buy-wisely checklist as the newsletter lead magnet, SEO buying-guide articles, and an internal link builder that adds the SubID to any Shopee link. WHAT IT SHOWS Most affiliate sites compete on hype. GoOdays competes on being checkable: zero invented ratings or prices, and a tracking setup that tells you which placement earns.
