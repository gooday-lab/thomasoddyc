02PORTFOLIO PROJECT

Data Validation Rule Engine (Excel VBA)

Portfolio project - all data is fictional and simulated. The problem always has the same shape: a batch of transaction data arrives, and a regulation decides which fields are mandatory, which are optional, and what valid means for each one. Five thousand records. Manual checking does not scale - and it never leaves a trail. So I made the regulation executable. THE RULE SHEET 18 rules over 14 fields: patterns, lengths, reference lookups, a product-to-category map, numeric ranges, date windows and duplicate detection. Every field is flagged mandatory or optional. Every rule carries a severity - blocking or warning - and an auto-fix switch. Changing the regulation is a one-row edit in Excel, not a code change. THE ENGINE One button runs the batch in seconds. It cleans first and judges second: name casing, stray spaces, phone separators, canonical reference values, category rebuilt from the product map, dates normalised - every change written to a fix audit column. Then the rules run, every rejected cell is marked, and each row gets a verdict: valid, warning, or invalid. WHAT CAME OUT 5,000 records in, 3,851 accepted, 413 accepted with warnings, 736 rejected with a precise reason. 1,263 violations caught before they reached reporting. 5,256 cells repaired automatically. First-pass compliance: 77.02%. THE DELIVERABLES An error report with one row per violation. Valid and invalid CSV splits for downstream systems. An append-only audit log with run id, user, counts and duration. And a separate dashboard workbook - 7 KPI cards, 6 native Excel charts - that rebuilds from the engine's statistics export with one click. Pure Excel VBA. No add-ins. Fully reproducible.

03PORTFOLIO PROJECT

Sales performance dashboard in Power BI.

Portfolio project - all data is fictional and simulated. A sales performance dashboard built in Power BI: one semantic model, nine DAX measures and a single-page report covering sales, profit, margin and the monthly trend, with region and category breakdowns. It is saved as a PBIP (Power BI Project), so the model and the report are plain text and can live in Git. Download the project files and open SalesDashboard.pbip in Power BI Desktop.

04LIVE PROJECT

GoOdays: curated product picks with honest reviews.

Live project - a real site with real products. GoOdays is an Indonesian product curation site: top picks, reviews with pros and cons, weekly deals and buying guides. Every buy button is a Shopee Affiliate link tagged with its own SubID per placement, so the affiliate report shows which button actually works. Prices and ratings are only shown when they can be verified. No invented numbers. Visit: https://goodays.pages.dev
